# Stack

## Runtime Dependencies

None. The library uses modern JavaScript/TypeScript built-in primitives (`Uint8Array`, `TextEncoder`, `TextDecoder`).

## Dev Dependencies

- `fast-check`: Property-based testing for distributed convergence verification.
- `@trysac/mcp-server-template`: Dev integration testing for collaborative MCP server tools.
- `@trysac/retry-policies`: Dev integration testing for retry policies during sync.
